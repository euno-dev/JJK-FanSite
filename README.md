# Jujutsu Kaisen Fan Site

A fan-made, multi-page static website dedicated to the world of **Jujutsu Kaisen**.  
This project was developed as part of our web development requirement to demonstrate frontend development skills, website structuring, and team collaboration.

---

## ⭐ Overview

**JJK-FanSite** is a simple, clean, and easy-to-navigate website that includes:

- Character profiles  
- Villain highlights  
- Episodes & summaries  
- Static image gallery  
- About and Contact pages  

The project focuses on strong HTML structure, clean CSS styling, consistent UI, and lightweight JavaScript for simple interactions.  
It is a **fully static website** with no backend or database.

---

## 🎯 Rationale / Background

This project helped our group apply what we learned about:

- Building and organizing a multi-page website  
- Writing clean, readable HTML and CSS  
- Applying a consistent design theme across pages  
- Using GitHub for collaboration and version control  
- Creating a content-rich site based on a popular anime franchise  

We chose **Jujutsu Kaisen** because of its visually rich world, diverse characters, and fan-friendly theme.

---

## ✨ Features

- Multi-page layout (Home, Characters, Villains, Episodes, Gallery, About, Contact)  
- Simple and consistent navigation bar  
- Character and villain information cards  
- Static gallery layout  
- Clean and maintainable code structure  
- Lightweight JavaScript functionality  
- Works on any modern web browser — no installation needed
